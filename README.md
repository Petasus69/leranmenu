# Меню на память

Локальный веб-тренажёр для изучения состава блюд из Markdown-файлов.

## Запуск

```powershell
npm start
```

Откройте `http://127.0.0.1:4173`. Тесты запускаются командой `npm test`.

Для остановки нажмите `Ctrl+C` в окне запущенного сервера. Если сервер работает в другом терминале, выполните:

```powershell
npm stop
```

## Формат рецепта

Название берётся из имени файла либо из `title` в YAML. Ингредиенты — маркированный список в разделе `### Состав`:

```md
---
title: Томаты кимчи с муссом из феты
category: Закуски
---

### Состав
- [[Маринованные томаты]]
- [[Мусс из феты]]
- *Кунжут кимчи*
```

Ссылка `[[Мусс из феты]]` связывается с файлом `Мусс из феты.md`. Если в нём тоже есть раздел «Состав», приложение автоматически добавит следующий уровень тренировки. Глубина вложенности не ограничена; циклические ссылки безопасно пропускаются.

Вложенные Markdown-списки тоже становятся следующими уровнями:

```md
- Лук в вине
  - Красный лук
  - Вино
```

Подпункты такого списка разворачиваются в тот же состав: «Красный лук» и «Вино» нужно назвать как обычные ингредиенты текущего блюда, отдельного перехода для «Лука в вине» не будет. Внутренний состав открывается только для ссылок `[[...]]` и только после того, как полностью завершён текущий состав. Затем по тем же правилам проходятся связанные компоненты следующего уровня.

Если один файл содержит несколько заголовков-позиций с вложенными разделами `#### Состав`, каждая позиция загружается как отдельное блюдо. Папки, начинающиеся с `Определения`, `Компоненты`, `Заготовки` или `Полуфабрикаты`, считаются библиотекой внутренних компонентов: их можно раскрывать из блюда, но они не участвуют в случайном выборе.

Категория берётся из `category/categories` в YAML или из имени папки при загрузке каталога. Данные и статистика хранятся только в `localStorage` браузера.

При проверке ответа регистр, `ё/е`, порядок слов и знаки препинания не учитываются. Символ `%` можно не вводить. Слова `перец` и `сыр` в составных названиях необязательны: например, для «Перец чили» принимается «чили», а для «Сыр Дор Блю» — «дор блю». Слово `соус` всегда обязательно.

В списке базы можно отметить несколько блюд и запустить тренировку только по этой подборке. Поиск позволяет быстро отфильтровать и выбрать все найденные позиции. На странице статистики кнопка «Повторить все ошибки» запускает последовательную тренировку всех блюд, в которых ранее были ошибки.
